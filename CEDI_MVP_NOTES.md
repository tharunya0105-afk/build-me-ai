# Build Me — CEDI MVP

## Product thesis
Build Me is positioned as a digital planning layer for residential construction and renovation in India: **idea → project → indicative budget → visualization → professional discovery → consultation**.

## What changed in this MVP
- Replaced the old construction-tool/demo language with a homeowner-first workflow.
- Added four clear entry paths: build, renovate, estimate, find a professional.
- Added guided project creation with type, city, area, budget, style, bedrooms and bathrooms.
- Added transparent range-based budget estimation with category breakdown and assumptions.
- Added demo professional discovery and consultation intent.
- Added local early-access/validation capture using localStorage for the no-backend MVP.
- Added a 3–5 minute evaluator demo journey.
- Removed fake traction/statistics and explicitly labels demo professionals.
- Added responsive mobile layout and accessible form controls.

## Current limitations to say honestly
- There is no production database/authentication yet.
- Professional profiles are demo data.
- Budget rates are prototype assumptions, not live market rates or quotes.
- Visualization is represented as the next product layer rather than pretending the existing canvas is a true 3D engine.
- Early-access submissions are stored locally in this prototype and are not yet a real lead database.

## Recommended validation milestones
1. Interview 20–30 homeowners who recently built/renovated.
2. Collect 10+ real project budgets and normalize assumptions by city.
3. Recruit 5–10 real professionals for a pilot.
4. Measure project creation → estimate completion → consultation request conversion.
5. Replace sample rates/profiles with verified pilot data.
6. Add a real backend only after the workflow shows repeatable demand.

## Suggested first business model
Start with **professional lead generation / consultation requests**. It aligns revenue with a high-intent event while avoiding premature subscriptions or marketplace complexity.

## Future data advantage
Structure future data around city, project type, area, budget, material choices, professional response, consultation outcome and eventual project outcome. This can support increasingly useful regional estimates and matching over time.
